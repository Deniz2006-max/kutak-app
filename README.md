# Kutak Dashboard

UI prototype for **Kutak** — Koç University taxi-share. Verified `@ku.edu.tr` users browse and host 4-seat ride cards.

## Run locally

```bash
cd kutak-dashboard
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Scripts

- `npm run dev` — development server
- `npm run build` — typecheck + production build
- `npm run preview` — serve the production build
